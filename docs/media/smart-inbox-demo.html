Your inbox, triaged the moment it arrives.

Smart Inbox reads every incoming email, classifies it with an LLM, and routes it where it belongs. Urgent alerts go to Discord, leads get enriched and logged, support replies are drafted for you, and the whole flow streams to a live dashboard.

        Smart Inbox
        

          A real inbox, triaged by a real pipeline. OAuth, orchestration, classification, routing,
          and the dashboard it all lands in, built end to end.
        


        

          

            
Bring your own OAuth

            

              Each user supplies their own Google Cloud app. The backend runs the consent flow,
              injects the credential into n8n, then builds and activates a workflow that belongs to
              that user alone.
            

          

          

            
Proof without a connection

            

              Simulate runs a typed email through the same classifier and the same routing with no
              Google account attached, so the pipeline can be watched working in seconds.
